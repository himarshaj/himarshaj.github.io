This project developed storytelling solutions to improve the discovery and understanding of web archive collections. I contributed to several components of the [DSA project](https://oduwsdl.github.io/dsa/), including AIU, Raintale, and MementoEmbed. AIU is a Python library that gathers seed URLs and metadata from web archive collections such as Archive-It, Pandora, and Trove using APIs and screen scraping. MementoEmbed generates archive-aware cards for individual mementos, while Raintale organizes these cards into engaging, shareable stories. Taken together, these tools help transform large and complex web archive collections into accessible and meaningful experiences for archivists, researchers, and the public.
